# Project Positioning

## 推荐中文定位

基于 Isaac Lab 与 MotrixLab 的 ANYmal-C 四足机器人复杂地形导航迁移项目。

## 推荐英文定位

ANYmal-C rough-terrain navigation transfer with Isaac Lab and MotrixLab.

## 一句话介绍

本项目基于现有机器人仿真与强化学习框架，将 ANYmal-C 导航任务从平坦地形迁移到复杂地形，并完成 HeightScan 策略适配、训练评估和 PPO 学习率稳定性分析。

## 面向简历的项目边界

这个项目不应包装成“从零实现强化学习框架”。更准确、更可信的表达是：

> 基于 Isaac Lab / MotrixLab 现有框架，完成 ANYmal-C 复杂地形导航任务迁移、策略配置适配、训练评估和优化分析。

这样能突出工程能力、框架阅读能力和实验分析能力，也经得起面试追问。

## 核心价值

- 机器人任务迁移：从 flat terrain navigation 迁移到 rough terrain navigation。
- 复杂地形感知：使用 HeightScan 观测与预训练策略，让机器人具备地形高度感知能力。
- 训练稳定性分析：通过学习率、episode length 和策略收敛表现解释训练抖动来源。
- 项目展示整理：将原始实习材料整理为可读、可展示、可放入简历的 GitHub 项目。

## 推荐 GitHub About

Sim-to-sim transfer project for ANYmal-C quadruped navigation on rough terrain, with HeightScan policy adaptation and PPO training stability analysis.
