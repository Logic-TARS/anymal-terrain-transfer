# PPO Training Stability Analysis

## 现象

训练过程中，学习率曲线呈现明显的震荡衰减趋势，大致从 `2e-4` 降至 `2e-5`。同时，最小 episode length 在训练前中期出现剧烈波动，说明策略虽然已经初步学到有效行为，但优化过程仍不稳定。

## 原因分析

学习率表现更接近基于 KL divergence 的自适应调整机制，而不是平滑的固定线性衰减。

在约 2k-6k 步区间，学习率仍高于 `1e-4` 且波动明显。对于 PPO 来说，过大的策略更新步长容易破坏已经形成的局部稳定策略，使机器人在复杂地形任务中出现行为抖动，进而反映为 episode length 的剧烈变化。

当训练进入 10k 步以后，学习率逐渐收敛到 `5e-5` 以下，策略更新幅度变小，模型才能在较优解附近进行更细粒度的优化，性能波动随之减弱。

## 优化建议

### 1. 使用线性学习率衰减

将自适应学习率调整替换为标准线性衰减，让学习率随训练进程平滑下降，减少 KL 波动带来的更新不稳定。

适用场景：

- 训练步数较短
- 环境奖励较稀疏或不稳定
- episode length 波动明显
- 策略已经初步成型但容易退化

### 2. 降低初始学习率

如果总训练步数只有约 2.4 万步，`2e-4` 的初始学习率偏激进。可以尝试：

- `1e-4`
- `5e-5`

这会降低早期策略破坏风险，使训练更平滑。

### 3. 联合观察多个指标

不要只看 reward 或 episode length。建议同时观察：

- learning rate
- KL divergence
- episode length
- policy loss
- value loss
- entropy
- termination statistics

如果学习率峰值与 episode length 下跌同步出现，通常说明 PPO 更新过大，策略在短时间内偏离了稳定行为。

## 结论

本次训练中的主要问题不是“策略完全学不会”，而是“策略初步成型后被过大的自适应学习率反复扰动”。因此，优化重点应放在降低早期更新幅度和提升学习率曲线平滑性上。
